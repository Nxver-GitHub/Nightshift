# clients/

One folder per client, created when they sign (or when a prospect gets real enough to track).

Each client folder uses the same structure as any entity — copy `kit/templates/entity/` from the
Sunday kit:

```
clients/<client-slug>/
├── main.md      ← who they are, State as of, contacts
├── notes/       ← people.md (their contacts), anything useful
├── docs/        ← contracts, offers
├── logs/        ← dated history
└── projects/    ← the work you do for them
```

*(Empty in this example — Acme Flows hasn't signed its first practice yet.)*
