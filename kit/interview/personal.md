# Founding interview — personal / life brain  *(stub — not built yet)*

Personal mode isn't implemented in v0. Sunday today is tuned for **creating a company**.

If a user asks for a personal "second brain":
1. Tell them plainly that personal mode is coming, not ready.
2. Offer the nearest thing: run `kit/interview/company.md` adapted to a **solo project or venture**
   — it produces a perfectly good single-owner brain (skip the client/GTM phases if irrelevant).
3. Or stop, and note their interest.

### When we build this later
Personal mode should reuse the same ontology (three-subfolder structure, `main.md` discipline,
people, logs, safety floor) with a different seed: a `life/` or `me/` root instead of a company,
top-level areas (health, finance, relationships, projects, admin) instead of clients, and an
interview about goals, routines, people, and what the founder wants an assistant to handle. The
crown jewel is the same — the interview, not the folders.
